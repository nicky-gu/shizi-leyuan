# 🌈 暑假识字乐园

> 一年级升二年级 · 20 天学会二年级上册 607 个生字

一个为小朋友设计的识字网站：**每日学习 + 艾宾浩斯记忆曲线复习**，纯前端、零成本部署。

## ✨ 功能

### 📖 每日学习模块（4 种多样化练习）
| 模式 | 说明 |
|---|---|
| 🃏 识字卡片 | 大字卡片 + 拼音 + 点读发音（语音合成） |
| 🔊 听音选字 | 听读音，从 4 个字中选出听到的字 |
| 🅿️ 看字选拼音 | 看汉字选正确拼音 |
| 🔍 火眼金睛 | 在 12 个字中快速找到目标字 |

### 🔁 每日复习模块（科学记忆曲线）
- **自动制定每日任务**：根据开始日期，自动计算今天该学第几天的字、该复习哪几天的字
- **艾宾浩斯复习曲线**：学过的字在第 **1、2、4、7、15** 天自动到期，提上复习
- **错题优先**：之前做错的字排在复习最前面，并在「错题强化训练营」中随时可加练
- 复习练习方式随机（听音选字/选拼音/找字），保持新鲜感

### 📊 学习报告
- 已学字数 / 熟练掌握数 / 正确率 / 坚持天数
- 20 天学习日历（⭐ 打卡标记）
- 易错字墙（点击可听读音）

### ☁️ 跨终端同步
- 电脑、iPad、手机多设备共享同一份学习进度
- 基于 **GitHub 私有 Gist** 存储（数据在你自己账号下，安全免费）
- 首次使用生成一个 **同步码**（如 `SHIZI-K7M2QX`），其他设备输入同一同步码即可合并进度
- 每次练习结束**自动上传**，也可随时手动「上传 / 拉取」
- 智能合并：两台设备的进度取并集，每个字保留对错次数最多的记录

#### 🔒 同步安全说明
- 代码中**无任何硬编码凭据**，token 由用户首次使用时粘贴，仅存本机浏览器 localStorage
- **强烈建议**为同步创建一个【仅 `gist` 权限】的专用 token（不要用 full repo 权限的大 token），权限最小化
- 同步弹窗内提供「🔒 清除本机授权」可随时抹掉 token
- 数据流向只有：浏览器 ↔ GitHub 官方 API（你自己的私有 Gist），不经过任何第三方

## 📁 数据结构

- `data.js` —— 607 个生字（含拼音、课文分组）+ 20 天学习计划，由 `gen_data.py` 自动生成
- 学习进度保存在浏览器 `localStorage`，无需后端、无需注册

## 🚀 本地运行

纯静态文件，直接用浏览器打开 `index.html` 即可；或：

```bash
npx serve .
```

## ☁️ 部署到 Cloudflare Workers（免费）

1. 安装 wrangler 并登录：
   ```bash
   npm install -g wrangler
   wrangler login
   ```
2. 部署（仓库已包含 `wrangler.toml`）：
   ```bash
   wrangler deploy
   ```
3. 完成！会获得 `https://shizi-leyuan.<你的子域>.workers.dev` 免费域名。

> 免费套餐说明：Workers 静态资源请求免费额度 10 万次/天，个人使用绰绰有余。
> 也可以在 Cloudflare Dashboard → Workers & Pages → 直接连接 GitHub 仓库实现自动部署。
